# Capstone — Knowledge Assistant

A 30-week build of a Q&A assistant over a small document corpus, completed as part ofthe *Agentic AI & RAG Engineering* programme.

## Corpus

My capstone corpus: FastAPI documentation (5 pages: tutorial intro, dependencies,security, testing, deployment). 
Source: https://fastapi.tiangolo.com/

## Structure

 - `src/` — application code
 - `docs/adr/` — Architecture Decision Records (one per major design choice)
 - `docs/runs/` — saved LLM outputs for evidence and reference##
